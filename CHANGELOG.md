# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-12-16

### Added

- **Tourism Package Management** — Full CRUD operations with search, filtering, image support, and real-time seat availability tracking.
- **Booking System** — Real-time booking with instant seat checks, multi-status management (Pending, Confirmed, Cancelled), and smart cancellation with 15% processing fee.
- **Stripe Payment Integration** — Secure Stripe Checkout, real-time payment validation, automated refund processing, and multiple receipt formats (internal + Stripe invoices).
- **User Authentication & Authorization** — ASP.NET Core Identity with role-based access control (Admin/Customer), profile management, and email-based identification.
- **Admin Dashboard** — Analytics with interactive charts, user and package management, revenue analysis, and payment transaction monitoring.
- **Responsive UI** — Bootstrap 5 mobile-first design with professional payment interfaces and Indian Rupee (₹) currency support.
- **Database Layer** — Entity Framework Core 8.0 with SQL Server, automatic migrations, and seed data for roles, admin user, and sample packages.
